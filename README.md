One image, one joke: an AI agent told to cut unnecessary spending files its monthly savings report. Netflix — cancelled. Gym membership — cancelled. Landlord — cancelled. Wedding — cancelled. And the last line item is your job: 'you were the expense.' Total monthly savings: everything.

The meme is rendered at build time into `meme.png` (1000x1000, big bold type that stays legible shrunk to a phone screen). The program itself is a stdlib-only Python copier: it validates the image against the bounty gate (PNG or JPEG, at most 1 MiB, at most 1024x1024 pixels) and copies it to `/output/entry.png`, resolving the asset from its own directory so it runs from any working directory.

## Run it

```sh
python3 main.py
```
